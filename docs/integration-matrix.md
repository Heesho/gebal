## Application dependencies

Node 22.23.3; pnpm 10.34.6; TypeScript 5.9.3; Zod 4.6.5; smol-toml 1.9.0; Commander 15.0.0; tsx 4.23.15; Prettier 3.9.9. Versions were resolved through the official npm registry and pinned in package/lockfiles. `node:sqlite` is part of Node and has no external database service. These libraries/tooling run on the trusted controller; source execution is isolated separately. Node 22.13+ satisfies the selected CLI/tooling engines. The default shell on the implementation machine used Node 20, so validation explicitly used Node 22.23.3.

The lockfile pins transitive package integrity. See `dependency-licenses.json` for the locally installed dependency license inventory. Linked libraries carry their own licenses; tool subprocesses and services remain separate integrations. Check all distributed transitive notices before packaging external dependencies. No assessment invokes npm/pnpm or executes an assessed project's install scripts.

## Own-agent interoperability

Codex, Claude Code, other assistants and local models use the same local context JSON and response schema, without a Gebal provider key. No assistant SDK/CLI is spawned or privileged by Gebal. Runtime credentials, model settings, egress and cost remain under the operator's external tool/account. Review imports record that provenance as unverified and cannot satisfy deterministic task outcomes. This is file-protocol interoperability, not a tested direct integration with every named assistant.
