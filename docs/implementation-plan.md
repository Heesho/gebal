# First iteration: a repository you use with your own AI

The owner clarified that the first iteration is a GitHub-style developer repository, not a V12-style website. The implementation is CLI-first and ships agent instructions plus a validated context/export-import protocol. No web application, HTTP control plane or hosted service is included.

1. Versioned domain schemas, immutable source/evidence and SQLite queue.
2. Literal authorized paths, bounded snapshots, conservative Foundry diagnosis and exact-plan approvals.
3. Source-only runs with no Docker or API requirement. Export cold source context for the owner's existing Codex, Claude Code, other assistant or local model.
4. Import inert source-linked JSON observations, preserve uncertain provenance, require human triage and never turn an AI result into execution proof.
5. Optional restricted Docker Foundry/Slither checks and optional direct OpenAI/Anthropic APIs under approved execution/egress budgets.
6. Markdown/JSON/HTML/SARIF reports, comparison, isolated infrastructure evaluations, regression tests, CI and clear setup instructions.

The implementation is original MIT-licensed code. Referenced tools, libraries and methods retain their own licenses. No third-party method pack is imported. Publishing the source repository requires owner authorization; package publication, DNS, websites and deployments remain separate actions. Later orchestration/property/evaluation work follows demonstrated usefulness, not agent count or a dashboard.
